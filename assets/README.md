# Original sprite artwork

All PNG artwork in this directory is 100% original work by **Tim Hyatt of
Tim Hyatt Games**, created for **Pixels In Space**, his upcoming Steam game.
Tim supplied the artwork directly and confirmed ownership while preparing
this plugin for release on September 6, 2026. No third-party sprite pack is used.

This includes all friendly ships, enemy ships, bosses, bullets, thruster,
explosion and impact sheets, coins, and coin particles.

See [LICENSE](LICENSE) for permission to distribute the artwork with this
plugin and its previews. Reuse in another game or as a standalone asset pack
requires separate permission. The code's MIT license does not cover the artwork.

Attribution: **Artwork © 2026 Tim Hyatt / Tim Hyatt Games — Pixels In Space.**

The thruster files are `thrusters_sheet.png` and `enemy_thruster_sheet.png`;
each contains four 32×32 animation frames. Both are used by the renderer.
