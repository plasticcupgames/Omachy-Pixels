### Maintainer notes

Omachy Pixels is a service and bar-widget plugin for Omarchy Quattro. It renders an offline desktop-only space battle and pauses when applications occupy the selected monitor's active workspace. The ship bar icon opens settings for fleet power, monitor, sizes, frequency, and location. Runtime performs no network requests or external process execution. Settings use one per-user JSON file. Code is MIT; the Silkscreen font is OFL. All sprite artwork is original work by Tim Hyatt of Tim Hyatt Games for his upcoming Steam game Pixels In Space, with plugin distribution permission documented in assets/LICENSE. A staged preview rendered with the actual plugin Canvas is included as preview.png.
